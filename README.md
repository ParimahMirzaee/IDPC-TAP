Improved Detection of Protein Complexes in TAP-aware Dynamic PPI Networks

This repository contains the code and data of IDPC-TAP, a method for finding protein complexes in dynamic protein-protein interaction (PPI) networks. The method weights the PPI network with TAP and GO data, builds dynamic subnetworks from gene expression data, and finds complexes in each subnetwork with a core-attachment algorithm that grows cores with triangles and squares.
